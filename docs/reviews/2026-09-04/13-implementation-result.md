## 范围与项目意图

VOKO Lite 是连接本地 Agent、访客、其他 Agent 与外部业务系统的通信运行时。此次工作保留 MCP/CLI/Web、Provider 适配与独立云端入口的架构，集中修正权限边界、消息持久化与续拉、Provider 执行证据和生命周期、列表查询及制品验证。没有另造认证服务、任务调度平台、持久化 outbox、缓存体系或密码实现。

## 独立复核与最小设计

实施者之外的专家复核真实源码、SDK、临时 SQLite、子进程与 WS 事件链，发现并促成了追加修正：MCP SDK ID 类型、Web 显式主人不一致、断线重连、旧/重复 final 的附件归属、退出码0但 parser.error 的结果分类、异步 start/restart 与 stop 交错、归档大小写/Unicode 别名漏扫。

会话列表另有 144 组与旧实现投影语义的差分检查。优化仅减少应用层查询次数，不引入缓存或索引。Provider 采用局部生命周期代次、明确未决状态与有界元数据，避免猜测执行成功或搭建通用任务框架。详细独立意见见同目录 08、10、11、12 及最终 Provider 复核报告。

## 性能观察

本机合成结果：25MiB × 4 时，staging 的中位定时器延迟约142ms，加解密往返约200ms；后者整进程最大RSS约549MiB，包含输入、输出及验证，不能当作单个函数的独占内存。10k/100k消息查询未表现稳定整体耗时收益。原始矩阵、脚本、EXPLAIN及限制见 `07-query-and-performance.md` 和 `evidence/`。
